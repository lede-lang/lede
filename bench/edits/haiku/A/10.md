# How login works on the member portal

Pinecrest Credit Union. Identity team. Draft dated 2026-10-08.

## Login flow

```mermaid
sequenceDiagram
    participant User
    participant Browser
    participant Web App
    participant Auth Server
    participant Profile API

    User->>Browser: click Sign in
    Browser->>Web App: GET /login
    Web App-->>Browser: 302 to /authorize with PKCE challenge
    Browser->>Auth Server: GET /authorize
    Auth Server-->>User: show login and MFA prompt
    User->>Auth Server: credentials + MFA code
    Auth Server-->>Browser: 302 to /callback with code
    Browser->>Web App: GET /callback with code
    Web App->>Auth Server: POST /token with code verifier
    Auth Server-->>Web App: access token + ID token + refresh token
    Web App->>Profile API: GET /me with bearer token
    Profile API-->>Web App: profile JSON
    Web App-->>Browser: set session cookie, render dashboard
    Web App->>Auth Server: refresh_token grant
    Auth Server-->>Web App: new access token
```

## Tokens

| Token | Lifetime | Stored where |
|---|---|---|
| Access token | 15 minutes | Server-side session |
| ID token | 15 minutes | Server-side session |
| Refresh token | 30 days | Encrypted session store |
| Session cookie | 12 hours | Browser (HttpOnly, Secure) |

## Security notes

- PKCE is mandatory.
- MFA is required for every member.
- Failed logins lock the account after 5 attempts.

> **Warning:** Tokens must never be exposed to browser JavaScript or kept in browser storage.
