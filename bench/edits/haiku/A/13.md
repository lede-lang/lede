# Monorepo deployment pipeline

Developer Productivity, Quillstone Software. As of 2026-10-10.

## Pipeline diagram

```mermaid
flowchart LR
    pr["Pull Request"] --> lint["Lint and Unit Tests"]
    lint -- "pass" --> build["Build Image"]
    build --> scan["Security Scan"]
    scan -- "no critical CVEs" --> staging["Deploy to Staging"]
    staging --> integ["Integration Tests"]
    integ --> smoke["Smoke Tests"]
    smoke -- "pass" --> approval["Manual Approval"]
    approval -- "approved" --> canary["Canary 10%"]
    canary -- "healthy 30 min" --> full["Full Rollout"]
    canary -- "error rate above 1%" --> rollback["Auto Rollback"]
```

## Rules

- Manual Approval is required only for services tagged tier-1.
- Friday deploys after 15:00 local time are blocked.
- Auto Rollback pages the owning team.
