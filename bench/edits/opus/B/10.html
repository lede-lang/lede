How member portal login works

Pinecrest Credit Union · Identity team

Login flow

Request or actionResponse or redirect
Read the steps as text
  1. User → Browser: click Sign in
  2. Browser → Web App: GET /login
  3. Web App → Browser: 302 to /authorize with PKCE challenge
  4. Browser → Auth Server: GET /authorize
  5. Auth Server → User: show login and MFA prompt
  6. User → Auth Server: credentials + MFA code
  7. Auth Server → Browser: 302 to /callback with code
  8. Browser → Web App: GET /callback with code
  9. Web App → Auth Server: POST /token with code verifier
  10. Auth Server → Web App: access token + ID token + refresh token
  11. Web App → Profile API: GET /me with bearer token
  12. Profile API → Web App: profile JSON
  13. Web App → Browser: set session cookie, render dashboard
  14. Web App → Auth Server: refresh_token grant
  15. Auth Server → Web App: new access token

Security notes

  • PKCE is mandatory on every authorization request.
  • MFA is required for every member.
  • Failed logins lock the account after 5 attempts.
Never expose tokens to the browser Access, ID and refresh tokens must never be exposed to browser JavaScript or kept in browser storage (localStorage, sessionStorage or IndexedDB). The browser holds only the HttpOnly session cookie.
