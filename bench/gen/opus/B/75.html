How single sign-on works for the course portal

The calls between the browser, the portal and the identity services when someone signs in, how long each token lasts, and the rules that apply.

  • ForPlatform team
  • Version2026-10-08
60SEC

A one-time code expires after 60 seconds and works only once.

A second attempt with the same code, or any attempt after 60 seconds, must fail. Steps 8 to 10 below.

Sign-in sequence

request reply or redirect carries the one-time code
  1. Browser → Course Portalopen /courses
  2. Course Portal → Browserredirect to Identity Provider
  3. Browser → Identity Providerauthorization request with PKCE
  4. Identity Provider → User Directoryverify credentials and groups
  5. User Directory → Identity Providerverified, groups returned
  6. Identity Provider → Token Serviceissue tokens
  7. Token Service → Identity Providertokens issued
  8. Identity Provider → Browserredirect with one-time codeCode expires after 60 s · works once only
  9. Browser → Course Portalone-time code
  10. Course Portal → Token Serviceexchange code for tokensThe code is used up here
  11. Token Service → Audit Logrecord sign-in
  12. Course Portal → Browsersession cookie, 24 hours

Rules

  • Staff accounts

    Staff accounts must pass MFA.

  • One-time codes

    A one-time code can be used once only.

  • Audit

    Sign-in events are kept for 400 days.
