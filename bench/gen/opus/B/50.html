How a soil sensor gets provisioned

  • Written by IoT platform team
  • Dated 2026-10-14
  • Rollout 31 sites

Each sensor pairs with a site gateway over Bluetooth, is claimed with a one-time token, receives a signed certificate, and then starts sending telemetry over TLS. This page shows that exchange, the limits you will run into, and what to do when it fails.

Never photograph the one-time token QR code.The token claims a device. Anyone with a picture of it could use it. Scan it directly and move on.

Limits and timeouts

ItemValue
One-time token validity24 hours
Pairing window on the sensor90 seconds
Signing key typeECDSA P-256
Claim attempts before the token is locked3
Certificate lifetime365 days

When provisioning fails

Token expired

The one-time token is older than 24 hours.

Do thisRequest a new token from the dashboard.

Pairing window closed

The sensor's 90-second pairing window ran out.

Do thisPress and hold the sensor button for 5 seconds to reopen it.

Token locked

The token was used in 3 failed claim attempts.

Do thisContact IoT support in #iot-support.

Reminder: never photograph the one-time token QR code.Not for a ticket, not for a teammate, not "just in case".
