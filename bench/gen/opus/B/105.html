Matchmaking and game server architecture

Owner: Backend ServicesReviewed 2026-09-22

Overview

Players are matched into 10-player games and placed on the nearest regional server fleet. Each region can run alone if another region fails.

Watch these in a regional failoverThe Player Profile Database and the Leaderboard Service are the only parts shared across regions. Everything else is duplicated per region.

Architecture

Swipe sideways to see the whole diagram.

The Global Edge routes each player to the closest region. The stacked purple box is one regional stack; all three regions are identical.

  • Players → Global Edge · connect
  • Global Edge → Matchmaker · queue request
  • Matchmaker → Regional Cache · skill ratings
  • Matchmaker → Player Profile Database · load profile
  • Matchmaker → Session Allocator · match of 10 players
  • Session Allocator → Game Server Fleet · start session
  • Players → Game Server Fleet · UDP game traffic
  • Game Server Fleet → Leaderboard Service · match results

Scaling

When more than 2,000 players are waiting in a region's queue, that region scales its fleet up to 400 game servers.

Regional failover checklistEach region runs on its own, so a failed region does not take down the others. The two shared parts, the Player Profile Database and the Leaderboard Service, are the ones to watch.
