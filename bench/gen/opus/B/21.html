Quarterly disaster recovery drill

Runbook and results · Drill held 2026-10-07

Scope

Restore the patient-scheduling service in us-east-2 from backups after simulating the loss of us-west-2.

Restore procedure

  1. Freeze writes in us-west-2.
  2. Restore the latest RDS snapshot in us-east-2.
  3. Restore the S3 attachments bucket from the replica.
  4. Deploy the service stack from the release tag.
  5. Warning: confirm the snapshot timestamp first.Promoting an old snapshot silently loses appointments. Check the restored snapshot's timestamp before switching DNS.
  6. Switch DNS for scheduling.bramble.example to us-east-2.
  7. Run the smoke test suite.
  8. Reopen writes.
