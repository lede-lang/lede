Online ticketing platform on Azure

How bookings move from passengers to the database, the payment provider and the scanners at our port terminals.

  • OwnerDigital Channels
  • RegionNorth Europe
  • Reviewed2026-09-22

Overview

Passengers book through Azure Front Door, which passes their requests to the booking web app in our Ticketing subscription. Every booking is written to one database and announced as an event, so that the scanners at the port terminals stay in step.

Flows

  1. Passengers → Front DoorHTTPS
  2. Front Door → Booking Web Apporigin request
  3. Booking Web App → Ticketing APIREST
  4. Ticketing API → Reservations DBSQL, port 1433
  5. Ticketing API → Payment Providercard authorization
  6. Ticketing API → Booking Eventsticket issued
  7. Booking Events → Port Terminal Scannerssync every 30 s
