How a 911 call is received and dispatched

Owner: Public Safety SystemsReviewed 2026-09-30Architecture

Overview

Calls arrive from the telephone carriers into the primary dispatch center, where they are routed, recorded in computer-aided dispatch (CAD) and sent out to field units by radio. A backup dispatch center across the county can take over if the primary is lost.

!
The backup center is never activated automatically. It is brought into service only when the shift supervisor declares the primary dispatch center unavailable.

Call path

Dashed boxes are outside both centers. Dashed arrows run continuously to the backup center so it is ready when needed.

  • Callers → Telecom Carriers · voice and caller location
  • Telecom Carriers → Call Router · SIP trunks
  • Call Router → CAD Server A · call record
  • CAD Server A → CAD Server B · state sync
  • CAD Server A → CAD Replica · asynchronous replication
  • Call Router → Standby Call Router · heartbeat
  • CAD Server A → State GIS Service · address lookup
  • CAD Server A → Radio Gateway · dispatch message
  • Radio Gateway → Field Units · P25 radio
