When the site is on satellite fallback

  • The Control Room sees one-minute averages, not full-resolution data.
  • The Edge Historian holds 72 hours of full-resolution data on site until the fiber link returns.

Overview

Turbine data is collected on site and summarized before it is sent to the operations cloud over a limited link. The grid operator receives output and availability figures directly from the site.

Pipeline

Swipe sideways to see the whole pipeline.

  • Turbine Controllers → Site SCADA · 1 sample per second
  • Site SCADA → Edge Historian · buffered storage
  • Site SCADA → Grid Operator · output and availability, every 4 seconds
  • Edge Historian → Ingest Gateway · compressed batches over satellite or fiber
  • Ingest Gateway → Time-Series Store · validated samples
  • Time-Series Store → Forecast Service · history
  • Forecast Service → Control Room · 24 hour output forecast
  • Time-Series Store → Control Room · live and historical views

Satellite fallback: what changes for the Control Room

  • The 2 Mbps satellite link can carry one-minute averages only, so the Control Room sees averages, not full-resolution data.
  • Full-resolution data is not lost: the Edge Historian holds 72 hours of it until the fiber link returns.
