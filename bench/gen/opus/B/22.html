Decision page for the architecture review on 2026-10-21.

  • 1,800/speak messages

  • < 8 KBmessage size

Options

  • SQS — AWS's fully managed queue, using FIFO queues with message groups for ordering.
  • Kafka (Amazon MSK) — a managed, partitioned commit log with replayable retention.
  • RabbitMQ (Amazon MQ) — a managed broker with exchange-based routing.

Pros and cons

SQS

Pros

  • Fully managed
  • Scales automatically

Cons

  • No replay
  • 256 KB message limit

Kafka (MSK)

Pros

  • Replay up to retention
  • Supports stream processing

Cons

  • Needs partition planning
  • We handle broker upgrades

RabbitMQ (Amazon MQ)

Pros

  • Flexible routing

Cons

  • We would own capacity planning

Recommendation

Recommended

Use SQS with FIFO queues keyed by order ID. It gives per-order ordering through message groups, needs no operations work, and is the cheapest option at an estimated $310 per month.

We will revisit this choice if the analytics team needs event replay in 2027.
