# Checkout Payment Flow

**Tidewater Grocers** · Payments Engineering · Version 2, 2026-09-22

## Payment sequence

```mermaid
sequenceDiagram
    participant Mobile App
    participant Checkout API
    participant Fraud Service
    participant Payment Gateway
    participant Ledger

    Mobile App->>Checkout API: POST /checkout with cart and card token
    Checkout API->>Fraud Service: score order
    Fraud Service->>Checkout API: risk score
    alt risk score above 80
        Checkout API->>Mobile App: step-up verification required
        Note over Checkout API,Payment Gateway: Payment Gateway is not called
    else risk score 80 or below
        Checkout API->>Payment Gateway: authorize amount
        Payment Gateway->>Checkout API: auth code
        Checkout API->>Ledger: record pending charge
        Ledger->>Checkout API: entry id
        Checkout API->>Mobile App: order confirmed
    end
```

## Latency budget

| Step | p95 budget (ms) | Measured p95 (ms) |
| --- | ---: | ---: |
| Fraud scoring | 120 | 96 |
| Authorization | 450 | **512** |
| Ledger write | 40 | 31 |
| Total checkout | 800 | **811** |

The first bar in each pair is the budget, the second is the measured p95.

## Open issues

> **Warning: Authorization is 62 ms over budget.**
>
> The gateway's us-east endpoint is called from us-west-2, adding cross-region latency. This pushes total checkout p95 to 811 ms, over its 800 ms budget.

Next steps:

- Move to the gateway's regional endpoint.
- Add a 2-second timeout with one retry.
- Alert when total checkout p95 exceeds 800 ms.
