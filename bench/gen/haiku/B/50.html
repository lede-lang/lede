Limits and timeouts

ItemValue
One-time token validity24 hours

Signing key typeECDSA P-256
Claim attempts before the token is locked3
Certificate lifetime365 days

When provisioning fails

  • Token expired. Request a new token from the dashboard.
  • Pairing window closed. Press and hold the button for 5 seconds to reopen pairing.
  • Token locked after 3 attempts. Contact IoT support at #iot-support.
Never photograph the one-time token QR code. A photographed token can be used to claim a device.
