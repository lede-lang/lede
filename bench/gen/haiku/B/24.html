Choosing a frontend framework for the scheduling admin rewrite

Internal Tools guild, Wrenfield University IT.

We are rewriting the course-scheduling admin app. It has about 60 screens, five developers, and is mostly forms and tables. This page compares React, Vue and Svelte for that work.

Criteria

  • Team familiarity
  • Form and table libraries
  • Hiring pool
  • Bundle size
  • Long-term support

Comparison

Pros and cons

React

Pros

  • Four of five developers already know it.
  • The data grid and form libraries we need exist today.
  • The largest hiring pool of the three.

Cons

  • The largest bundle of the three, at 142 KB.
  • Its ecosystem changes often, so we will need to pick libraries carefully.

Vue

Pros

  • A smaller bundle, at 98 KB.
  • Gentle learning curve for the one developer who knows it.

Cons

  • Only one developer knows it, so the rewrite would need retraining.
  • The form and table ecosystem is good but thinner than React's.

Svelte

Pros

  • The smallest bundle, at 41 KB.
  • Very little boilerplate for form-heavy screens.

Cons

  • No one on the team knows it yet.
  • The smallest hiring pool, and the form and table libraries are fewer.

Recommendation

Recommendation: React Four of the five developers already know React, and the data grid we need exists today. That outweighs the larger bundle for an internal admin tool.
“We are optimizing for the next five years of maintenance, not the first five weeks of building.”
— Hannah Osei, guild lead

Note: Svelte was the favorite in the prototype spike. We will revisit it for smaller tools.
