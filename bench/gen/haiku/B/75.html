Course portal single sign-on

Kestrel Learning · Platform team · Version dated 2026-10-08

A one-time code expires 60 seconds after it is issued, and it works only once.

Sign-in sequence

Six parties: Browser, Course Portal, Identity Provider, Token Service, User Directory, Audit Log.

  1. 1
    Browser → Course Portal
    open /courses
  2. 2
    Course Portal → Browser
    redirect to Identity Provider
  3. 3
    Browser → Identity Provider
    authorization request with PKCE
  4. 4
    Identity Provider → User Directory
    verify credentials and groups
  5. 5
    User Directory → Identity Provider
    verified, groups returned
  6. 6
    Identity Provider → Token Service
    issue tokens
  7. 7
    Token Service → Identity Provider
    tokens issued
  8. 8
    Identity Provider → Browser
    redirect with one-time code
  9. 9
    Browser → Course Portal
    one-time code
  10. 10
    Course Portal → Token Service
    exchange code for tokens
  11. 11
    Token Service → Audit Log
    record sign-in
  12. 12
    Course Portal → Browser
    session cookie, 24 hours

Token lifetimes

Token or credentialLifetime
One-time code60 seconds
ID token10 minutes
Access token30 minutes
Refresh token8 hours
Session cookie24 hours

Rules

  • Staff accounts must pass MFA.
  • A one-time code can be used once only.
  • Sign-in events are kept for 400 days.
