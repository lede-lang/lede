Matchmaking and Game Server Architecture

Owner: Backend Services · Reviewed 2026-09-22 · For engineers joining the live team

Overview

Players are matched into 10-player games and placed on the nearest regional server fleet. Each region can run alone if another region fails.

  • Matchmaking time: median target 10 seconds; 95th percentile target 30 seconds.
  • Scaling: each region scales up to 400 servers when more than 2,000 players are waiting in the queue.

The Player Profile Database and the Leaderboard Service are the only shared parts. Everything else runs separately in each region, so these two are the ones to watch in a regional failover.
