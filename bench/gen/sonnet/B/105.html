Overview

Players are matched into 10-player games and placed on the nearest regional server fleet. Each region can run alone if another region fails.

Regions and capacity

Three regions run the same stack: us-east, eu-central and ap-southeast. Each has 150 game servers, and each server runs 6 matches of 10 players.

Scaling a region

Servers scale up to 400 per region when more than 2,000 players are waiting in the queue. At 60 players per server, that raises a region from 9,000 to as many as 24,000 concurrent players.
