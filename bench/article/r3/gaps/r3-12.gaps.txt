Lede cannot express an editor: no editable fields for times, durations or days, no rules checked as you type, no start-time picker, no weekly-pattern picker, no copy button, and no explanation that appears at the moment a rule breaks.
Substituted: a static rule check run on the exported schedule (pump overlaps, daily litres vs 52,000 L, 90-minute cap, 11:00-16:00 block, dusk window, Bing dry period, apple-zone adjacency), a weekly dot grid as the pattern view, a list of zone pairs that must never overlap as a stand-in for a picker, a range chart of Wednesday, and two copy-out code fences in the export layout (as exported; and a clearly labelled proposal changing only Z9 to 19:40).
All litres, overlap and day-of-week figures are my own arithmetic; the Oct 26 weekday assumes the year 2026. The apple-zone rule is ambiguous and is reported under both readings. Allocation breaches could not be fixed without inventing run times, so no new values were proposed for them.
The inner double quotes in the Z5 note became curly quotes in the data table (the code fence keeps the straight quotes).
